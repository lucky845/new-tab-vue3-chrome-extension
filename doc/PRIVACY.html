隐私说明

New Tab Pro（下称"本扩展"）是一个纯本地的新标签页扩展：没有账号、没有服务器、没有遥测。

这一页如实说明它在你浏览器里存了什么、什么时候会联网、向谁发请求。

最后更新：2026-11-16 · 对应版本：2.0.0

一句话

你的数据不会离开这台设备。 唯一的外发是你自己会看到的那几次取数请求（天气、壁纸、站点图标），

它们的目的地和内容都在下面列清楚了。

本扩展不做什么

  • ❌ 不收集、不上传任何个人数据，没有任何自建服务端
  • ❌ 不注入内容脚本，不读取、不修改你在其他网站的页面
  • ❌ 不接入任何统计、埋点、崩溃上报、广告 SDK
  • ❌ 不读取浏览历史、书签、Cookie、密码
  • ❌ 没有远程代码：所有脚本都打包在扩展内（MV3 CSP script-src 'self'）

申请了哪些权限

权限为什么需要
storage保存设置、壁纸缓存、快捷访问、待办、便签、番茄钟等全部本地数据
geolocation天气组件定位到所在城市。只有你点"允许定位"才会取坐标，拒绝也不影响其他功能，可手动输入城市
host_permissions仅 10 个自有接口/图床域名的跨域请求（见下表）。不包含 *://*/*，不申请任何网站的访问权，不注入脚本

存了什么（全部在本机 chrome.storage.local）

存储键内容
settings / themeSettings界面设置、主题色、字体等
quickAccessSites快捷访问的站点名、URL、自定义图标（data:image）
todos / notes待办与便签文本
pomodoroSettings / pomodoroStats番茄钟的设置与历史统计
savedWallpaperId / savedWallpaperUrl / savedWallpaperData / savedWallpaperBlob / savedWallpaperBlobUrl当前壁纸的元信息与图片缓存
searchEngine / customEngines / searchHistory / engineIcons / engineLogos搜索引擎选择、自定义引擎、搜索历史、引擎图标
om_weather_<纬度>_<经度> / ntce-sun-* / geo*天气、日出日落、地理编码的缓存（坐标保留两位小数，约 1 km 精度）
demoFolderSeeded是否已插入过一次演示文件夹

清除方式：扩展详情页 →「网站数据」→ 清除，或直接卸载扩展。卸载即彻底删除，本扩展没有任何副本在别处。

什么时候联网、向谁

只在对应功能被使用时发请求，全部为 HTTPS：

目的地何时发送了什么目的
api.open-meteo.com / geocoding-api.open-meteo.com显示天气；搜索城市坐标或城市名天气与地理编码
restapi.amap.com天气设置里使用高德天气源时坐标或城市名中文城市天气
t0.gstatic.com（Google favicon 服务）渲染未自定义图标的站点方块时该站点的域名取站点图标
picsum.photos / fastly.picsum.photos浏览/使用 Picsum 壁纸源时常规 HTTP 请求头取壁纸缩略图与原图
api.pexels.com / images.pexels.com浏览/使用 Pexels 壁纸源时常规 HTTP 请求头（不含用户令牌）取壁纸列表与图片
wallhaven.cc / th.wallhaven.cc / w.wallhaven.cc浏览/使用 Wallhaven 壁纸源时常规 HTTP 请求头取壁纸列表与图片

这些第三方会像对待任何网页请求一样看到你的 IP 地址与请求时间，这是客户端直连无法避免的。

它们各自有自己的隐私政策，本扩展无法代替它们作出承诺。不使用某个功能，就不会有任何相关请求。

谁会收到请求取决于你的设置：

  • 壁纸：默认使用 Picsum；你去浏览 Pexels / Wallhaven 时才会请求对应站点
  • 天气：默认 Open-Meteo（免密钥）。只有在设置里填入高德 Key 之后，才会请求 restapi.amap.com
  • 站点图标：只对快捷访问里没有自定义图标的站点发起，且只带域名

需要特别说清楚的一件事

选「高德天气」时，天气查询会把坐标发给 restapi.amap.com（中国境内服务）。

如果你不希望坐标离开设备，请在设置里选默认的 Open-Meteo 源，或完全关闭天气组件。

不会发生的联网

  • 不加载任何远程 JavaScript / CSS / 字体
  • 不向自建服务器发送任何数据（本扩展没有服务器）
  • 站点图标只把域名本身作为 URL 参数发给图标服务，不带任何 Cookie 或访问记录

一个诚实的说明：站点图标与 host 权限

站点图标（favicon）由 Google 的 gstatic.com 服务提供，扩展没有申请这些站点的 host 权限 ——

卡片上显示的是服务端返回的图片，扩展本身拿不到你访问那些站点的任何内容。

儿童隐私

本扩展不面向儿童，也不收集任何年龄段信息或个人身份信息。

变更

本说明如有实质变更，会随扩展版本一起发布，并更新页面顶部的日期与版本号。
